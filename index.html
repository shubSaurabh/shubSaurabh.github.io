ML for AI security · Built at SecurITaaS Pte Ltd

AI risk engine: a fine-tuned ModernBERT encoder

Scores an AI agent's action before it runs. It checks whether the action matches the stated intent, marks prompt-injection spans in untrusted context token by token, and returns a calibrated risk score that sends risky calls to a human. I trained it from scratch with synthetic data, leakage-safe splits and calibration, and it serves on CPU at about 200 ms.
