Case study · ML for AI security

Scoring AI agent actions before they run

A fine-tuned ModernBERT encoder that gives each AI agent action a calibrated risk score, so risky calls go to a human. Built for SecretZero at SecurITaaS Pte Ltd.

Proprietary work, so this page covers the idea only, with no code or product details. Happy to go deeper in conversation.
149Mparameter encoder, three task heads
~200 mson a standard CPU
Calibratedscores with fail-closed fallback

What it does

Static rules decide which actions an agent may take, but not whether a particular call makes sense. The risk engine checks whether the action matches what the agent says it is doing, and whether untrusted content such as a ticket or a tool output tried to steer it. The score goes to a deterministic policy, and the model never grants permission on its own.

How I built it

  • Generated the training data myself, with labels built in by construction and test data the model never saw in any form.
  • Fine-tuned ModernBERT with three heads, including token-level detection of prompt-injection spans.
  • Calibrated, exported and served it on CPU, iterating over several versions to cut false alarms.
